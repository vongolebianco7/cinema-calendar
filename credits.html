Credits / Data Sources

CINEMAPは、利用条件が明確なAPI・オープンデータを優先して使用します。許諾が明確でない第三者サイトの評価・ランキング・上映時刻等は自動取得しません。

TMDB

This product uses the TMDB API but is not endorsed or certified by TMDB.

映画メタデータ、画像、公開日、TMDB評価等にTMDB APIを利用しています。

TMDB API attribution requirements

JustWatch

Streaming availability source

配信・レンタル・購入の提供状況は、TMDB Watch Providers APIを通じて提供されるJustWatchのデータを利用しています。Watch Providersの利用条件に従い、JustWatchをデータ提供元として表示しています。

TMDB Watch Providers / JustWatch attribution

Wikidata

CC0

全国映画館マスタには、CC0で公開されるWikidataの構造化データを利用します。上映時刻データとは分離して管理します。

Wikidata licensing

OpenStreetMap

ODbL 1.0

映画館ディレクトリのカバレッジ拡張にはOpenStreetMapの映画館データを利用できます。OpenStreetMap contributorsへの帰属を表示し、ODbLの条件に従って取り扱います。

© OpenStreetMap contributors / ODbL

Pexels / Francisco Davids

上映体験ページの比較画像には、Pexelsで無料利用可能なFrancisco Davids撮影の水中写真を使用しています。同一画像を各アスペクト比でクロップして比較します。

写真の出典

第三者サービス

Filmarks等、CINEMAPがデータ利用許諾または正式なAPIライセンスを保有していないサービスについては、評価点・ランキング・レビュー等を取得・保存・再掲載しません。必要に応じて通常の外部リンクのみ提供します。

YouTube / CRITIC MAP

Planned · disabled

人間による映画批評・考察への導線としてYouTube API Servicesの利用を検討しています。現在は本番連携を無効化しており、スクレイピングや動画本体の保存は行いません。利用条件・表示・データ保持・認証情報保護の要件を満たした後にのみ有効化します。

Privacy · YouTube Terms

Compliance

新規データソースは、本番利用前に利用規約、API条件、帰属表示、再配布・保存可否を確認します。確認できない場合は自動取得を無効のままとします。
