# Cinemap: 機能改善の道筋（2026-09-27）

## 目標

映画好きが「今日観る作品を探す → 一本を深掘る → 次の一本へ進む」を繰り返せること。機能数や滞在時間を増やすことを目標にしない。iPhoneを主な利用環境とし、既存機能、無料運用、`COMPLIANCE.md` の条件を守る。

## 第1段階：公開内容を正確に伝える（今回）

- 批評に確認済み出典がない間は、作品詳細から空の独立ページへ強く誘導しない。出典が揃った作品だけ、既存の出典付き表示を使う。
- カレンダーの劇場・配信・TV・映画祭の収録範囲を明記する。
- 再上映は確認済みの静的データを表示し、利用者操作による作品ごとの外部API連続照会を止める。

完了条件：出典ゼロ件でも架空の批評が見えず、各予定の網羅性と確認先が分かり、再上映画面を開いても外部APIへ連続照会しない。

## 第2段階：探すから次の作品までを一本につなぐ

- カレンダー内の詳細と作品検索内の詳細について、表示項目と戻る先を比較する。共通にする対象を決めてから改修する。
- 「公開・視聴タイムライン」と「現在の視聴状況」の重複を解消する。配信開始と現在の配信先の観測を混同しない。
- 監督・キャスト・受賞歴・関連作品から辿った先で、起点へ戻る導線を保つ。
- iPhoneで A（今週観る）、C（人物）、D（受賞歴）、E（作品詳細）の実操作を確認する。

完了条件：どの入口からでも作品の視聴方法と作り手を確認し、関連する別作品へ進める。出典や更新日が不明な情報は断定しない。

## 第3段階：批評を少数作品で成立させる

- `COMPLIANCE.md` に従い、利用条件を確認できた出典を人が読み、短い独自要約と出典リンクを静的データに登録する。
- 総評・評価点・対立点・割合は、それぞれ定められた出典数に達した場合だけ表示する。
- 情報不足をそのまま表示し、対象作品を増やすためのスクレイピングや有料AIは使わない。

完了条件：少数の掲載作品で、要約の意味と出典を読者が確認できる。未掲載作品では批評があるかのように誘導しない。

## 第4段階：My Cinemapの役割を決める

Filmarksと同じ鑑賞記録を作る前提にはしない。候補は「自分のベスト作品を出発点に、監督・年代・地域・未鑑賞作を辿る」体験。現行TOP10から実際に次の作品を見つけられるかを試し、必要な入力項目を確定する。

- まずTOP10から監督の別作品・関連作品へ進めるか確認する。
- 既存のリストを失わない保存・持ち出し方を検討する。
- 「観た／観たい」や独自評価は、その記録がCinemap固有の発見につながる設計を確認してから採否を決める。

完了条件：Filmarksの機能を複製する理由ではなく、Cinemapで記録を持つことで得られる発見を説明できる。

## 第5段階：正式公開前の確認

- iPhoneを中心に主要フロー A〜I を実画面で確認する。
- 静的データの鮮度・出典・対象範囲、外部サービスの利用規約、無料枠、アクセシビリティを確認する。
- 公開時に説明する機能と実際に使える機能を一致させる。P0が残る場合は正式公開を見送る。

第2〜4段階の詳細設計や実装範囲は、それぞれ前段階の結果を見て決める。
