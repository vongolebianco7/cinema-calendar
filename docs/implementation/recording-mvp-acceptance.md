# My Cinemap 記録 MVP — 受け入れ条件

- 主要な作品カードは作品詳細を開かず「観た」を押せる。再タップで取り消せる。操作は同一画面ですぐ反映し、ダイアログを出さない。
- 状態は未登録、観た、観た＋刺さったの三つ。「刺さった」は観た作品だけに追加でき、解除できる。未登録は未視聴という意味ではない。
- 記録は作品 ID ごとに、watched / resonated / updatedAt と作品の表示用メタデータを localStorage に保存する。全画面で共通のモジュールを使い、リロード後も維持する。
- 初回は約100本の混合ポスターから高速入力する。3列、即保存、上部件数、25本以上で My Cinemap への誘導、継続可。
- My Cinemap は記録数、刺さった数、証拠のある属性の内訳、固定100本集合の到達数と未登録作品を示す。既存のランキング画像作成機能も利用できる。
- 軽量な深海は記録数による段階表示。レベルや課金、外部への記録送信はしない。
- 個別解除と全リセット。全リセット時だけ確認する。狭幅 390px で横溢れせず、スクロール中に誤タップしにくい。
- 自動・手動テスト: 状態遷移、保存復元、検索・ランキング・おすすめ・人物・関連カード、連続タップ、リロード、解除、既存画像エディタ。

実装方針: 既存の静的 HTML 群に共通の記録モジュールとカード用小ボタンを導入し、記録専用ページを追加する。既存 `my-cinemap.html` は入口に記録画面へのリンクを置き、ランキング画像エディタは保持する。取得済みのランキングデータから登録候補集合を静的生成する。国と監督は根拠がある場合だけ集計し、外国映画の地域を憶測で分類しない。
