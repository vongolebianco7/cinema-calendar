# CINELVA 全画面共通操作仕様 — ブックマーク必須補足

2026-10-19。既存の全画面UI・UX統一仕様への追加。ロゴは変更しない。

| 操作 | 共通仕様 | 保存先・副作用 |
|---|---|---|
| ポスター・作品名 | 同一作品IDの独立した `search.html?id=…` の作品詳細へ | 記録を書き換えない |
| 採点ゲージ | 一覧上で0〜5点、0.1点刻みで直接保存 | 既存の鑑賞記録。既存のID・日付精度・コメント・未知フィールド保持 |
| 目のアイコン | `CinelvaQuickRate.open` の共通レビューポップアップ | 閉じるだけでは保存しない。保存は同一鑑賞記録へ |
| ブックマーク | `CinelvaBookmarks.bind/toggle` で見たい映画に保存／解除 | `cinelva-want-to-watch-v1` のみ。鑑賞済み・評価・日付・レビューを一切更新しない |
| 記録削除 | 鑑賞記録画面だけの追加操作 | 既存の削除・確認処理。ブックマークとは独立 |

## 適用対象

| 画面・表示箇所 | 共通操作の実装元 | 備考 |
|---|---|---|
| カレンダーの劇場公開／配信／TV作品 | quick-rate `enhanceCalendar` | 予定日を鑑賞日と誤認して自動保存しない |
| 作品検索一覧 | quick-rate `enhanceGrid` | カード内に操作ボタンを入れ子にしない |
| ランキング／受賞ランキング／興行収入 | quick-rate／`mountRankingGauges` | 同じゲージ・目・ブックマーク |
| 作品詳細 | `renderDetail` → `mountInline` | 大きい独自の記録ボタンを共通操作で置換 |
| My CINELVA 鑑賞した映画、カレンダー抽出、ジャンル抽出 | `card` → `mountFilmControls` | ポスター／作品名を独立詳細へ。削除は別操作 |
| My CINELVA 映画賞の既鑑賞・未鑑賞作品 | `card`／`mountFilmControls` | 未照合の作品IDは操作を捏造せず照合待ち |
| My CINELVA 監督作品一覧 | `mountInline` | imported IDはTMDB identityを使い、保存record IDは保持 |
| 見つけるの作品棚・条件検索・作り手の作品 | `CinelvaDiscoveryResolve` → `mountInline` | 検索条件／棚の展開操作とは独立 |
| My CINELVA 見たい映画 | `cinelva-watchlist.js` → `mountInline` | 鑑賞した映画の横の専用タブ。ダッシュボードには一覧を置かない |
| 再上映情報・劇場ディレクトリ・批評出典 | 作品詳細へのリンク／公式情報へのリンク | 固有の作品IDが無い行は直接保存しない。詳細で操作 |
| ヘルプ／規約／クレジット | 作品操作対象外 | ナビ・テーマ・戻る操作を維持 |
| バックアップ／実績画像 | 既存の共通バックアップ／出力処理 | ブックマーク操作で実行しない |

## データ・同期・失敗時

既存のキー・保存値を移行／初期化しない。読み込み時に旧local record IDを既存レコードの明示的TMDB IDへ解決する。既存の不明フィールド・保存日時を保持。旧IDとTMDB IDの重複は表示では同一作品にまとめ、解除時はその作品の同義キーだけ削除する。

同一ページの更新イベントと別タブのstorageイベント、履歴復帰のpageshowで再同期する。これは同一ブラウザ・同一オリジンの同期であり、端末間クラウド同期を意味しない。毎回最新の保存値を読む。壊れたJSON／不正形式／保存領域不足では、既存データを空オブジェクトに置換せずエラーを表示する。未知ID・矛盾する明示的identityは保存しない。

狭いカードは目／評価値／ブックマークと、その下の幅いっぱいの採点トラックでまとめる。スクロール操作と採点を分離する。My・見たい映画・詳細では44pxの目／ブックマークを確保。作品カード全体やページを横にはみ出させない。

## コード棚卸しと再発防止

`python scripts/inventory-ui-operations.py` で `quality/route-manifest.json` の全29ルートを走査し、実効canonical HTMLのbutton/input/select/textarea/summary/link、ローカルscript、動的ボタン生成、イベントハンドラ、保存書き込み箇所を `ui-operation-inventory.json` に出力する。`cinelva/*` は本番の既存redirect先を実効ソースとして記録する。

機能ごとの仕様は上表を正とする。新しい作品一覧は独自の保存処理や目／ゲージ／ブックマークを作らず `mountInline` を利用する。作品の確定IDが無ければ詳細検索へ誘導する。テストではブックマーク前後の鑑賞記録raw JSONを比較し、既存データ保持・別タブ同期・解除・再読込・狭幅配置を確認する。機械棚卸しは実行時の全分岐を保証するものではないため、ブラウザ検証と併用する。
