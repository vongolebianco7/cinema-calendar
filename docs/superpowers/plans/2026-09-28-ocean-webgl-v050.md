# Ocean WebGL v0.5.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Ocean's sprite/CSS primary renderer with a coherent native WebGL2 underwater ecosystem that is spacious, deterministic, iPhone-first, and free to operate.

**Architecture:** Keep `ocean-ecosystem.js` as the progression/domain source. Add focused native WebGL2 scene, geometry, shader, camera, and renderer modules; the Ocean entry mounts the renderer and retains a local fallback if WebGL2 cannot start. The old raster composition is not used as the primary v0.5 scene.

**Tech Stack:** Browser WebGL2, repository-owned JavaScript/GLSL, existing Python/Node tests, existing Playwright mobile CI.

**Spec:** `docs/superpowers/specs/2026-09-28-ocean-webgl-v050-design.md`

## Global Constraints

- Primary viewport: 390x844 iPhone-class Safari.
- No paid API, metered service, runtime AI, CDN dependency, scraping, tracker, or new recurring cost.
- No page-level horizontal overflow.
- `OCEAN v0.5.x` must be visible and renderer assets must carry matching cache keys.
- No per-fish circular/elliptical halo or attached bubble treatment.
- Preserve movie-recording/navigation journeys and existing rating semantics.
- Do not merge automatically; PR is the human review boundary.

## Review Focus

- WebGL2 unavailable/context loss: show a useful local fallback, never a black/broken scene.
- Touch gestures: drag travels across materially different regions; pinch is bounded; drag cannot become a tap selection.
- Determinism: identical ecosystem input produces identical entity placement/species parameters.
- Performance: cap DPR/entity counts and avoid per-frame object allocation where practical.
- First impression: overview/depth/habitat precede individual fish and UI.
