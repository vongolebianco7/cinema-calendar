# D-v3 completion contract

Automated implementation is complete only when:
- fish, rock, plant and light are cached image sprites;
- old procedural habitat helpers are absent;
- all five visual categories have provenance;
- runtime external and paid dependencies are zero;
- DPR is capped at 2;
- performance budget minimum remains 50fps;
- growth inputs remain wired;
- tests/CI pass.

Final Ocean adoption is a separate state and requires real iPhone G1/G2 + FPS evidence. This separation prevents a false 100% claim while allowing the implementation task itself to reach a durable checkpoint.
