# My Cinelva：映画棚・映画地図・プロフィール設計

作成日：2026-10-16（日本時間）
状態：設計レビュー用。実装・本番公開は未実施。

## 目的と合意した方向

採点した映画が蓄積することで、集める喜び、鑑賞範囲が広がる喜び、自分の映画遍歴が見える喜びを得られるようにする。

ユーザー指定：採点すると鑑賞済み扱い。独立した「観た」操作は設けない。監督別・受賞別・国別・今年／月別／累計などを深く見たい。初見／再鑑賞の比較や長文感想は優先しない。Oceanは開発中の実験室に置き、通常の記録を成立させる条件にはしない。

今回の提案：My Cinelvaに映画棚・映画地図・プロフィールを設ける。カレンダーは映画棚の表示切替。登録の手間が小さく、少数の記録でも成果が見えることを優先する。新しい推薦特集・SNS・ユーザー間順位は対象外。

## 比較する3画面

共通ヘッダー：My Cinelva、記録を追加、映画棚／映画地図／プロフィールのタブ。390px幅で主操作を収める。現在のマイランキングへは共通のサブナビゲーションから到達できる。

### A. 映画棚：採点するたびにポスターが増える

| 上からの順序 | 内容 | 操作・振る舞い |
| --- | --- | --- |
| 期間と実績 | 今年・今月・累計の記録作品数 | 年／月は鑑賞時期が分かる作品だけ。累計には時期不明も含む |
| 表示切替 | ポスター／カレンダー | 初期表示はポスター。利用者が切り替えられる |
| 絞り込み | 期間、国、監督、ジャンル、自分の点数 | 監督等の詳細フィルターは折り畳み。適用条件と解除操作を表示 |
| 映画棚 | 3列のポスター、自分の点数、作品名 | タップで記録詳細へ。画像がなくても作品名と点数は表示 |
| 時期不明の棚 | 鑑賞日が分からない過去の映画 | 全期間では別グループとして表示。年／月へ混入させない |
| コレクション | 自分で選んだ監督／映画賞等の棚 | 最初は最大3棚をピン留め。各棚から対象作品一覧へ移動 |

カレンダー：月表示は日付と件数、選択日の作品一覧。年表示は週単位の鑑賞作品数を4段階の濃淡で示す。月ラベルから月表示へ移動する。色以外に件数と読み上げラベルを提供する。年だけ分かる作品は年合計に含め、月・週へ推定配置しない。

空の状態：空白のグラフは並べず「好きな映画に点数をつける」操作と保存先の説明を表示。最初の1本から棚を使える。過去に観た映画のまとめ登録では検索結果から連続採点でき、毎回作品詳細を開く必要はない。

### B. 映画地図：国と年代の交点から作品を見返す

地理的な世界地図ではなく、行＝製作国、列＝公開年代のマトリクス。マスには本数を表示し、タップするとその条件のポスター一覧を画面内で開く。平均点表示へ切り替える場合も件数を残す。

- モバイルでは表示年代を5列に限定し、前後の年代へ切り替える。ページ全体の横はみ出しは作らない。
- 行は鑑賞本数の多い国から表示し、「ほかの国」で展開する。国名の読み上げを省略しない。
- 対象年代内の、記録がある国の空の交点は「この条件の記録なし」とする。未収録データと未鑑賞を混同しない。
- 少数の記録なら対象年代・国を絞って表示する。まだない地域を大量の空マスで埋めない。
- 次の段階で行＝監督へ切り替え可能にする。監督全作品の網羅や制覇率は前提にしない。
- 公開年を使用する。鑑賞年と取り違えない。製作国・公開年が不明の作品数を地図の外に明示する。

### C. プロフィール：自分が見せたい映画遍歴を一枚に

| 上からの順序 | 内容 |
| --- | --- |
| 自分のベスト | 手動選択した最大4作品。既存マイランキングから選べる |
| 記録の数字 | 累計、選択年、邦画／洋画／国不明、平均点と対象作品数 |
| 月別の推移 | 12か月の本数。値のラベル付き。時期不明・年のみの記録は別表示 |
| よく観る監督 | 本数上位と自分の平均点。タップで映画棚を絞り込む |
| 映画地図の要約 | 記録のある製作国数・公開年代と地図への入口 |
| 保存・共有 | 個別選択した内容だけを画像化。出力前にプレビュー |

表示例に使う数字はすべてデモと明記し、本番では作例を実記録のように表示しない。点数や監督から性格・人間性を断定するコピーは作らない。

プロフィールは当初このブラウザ内の画面。公開プロフィールURLや他者からの閲覧機能を含まない。共有画像には自由記述の感想、端末の識別情報を自動挿入しない。

## 記録の入口と状態

作品詳細と検索結果に「評価して記録」。0.0〜5.0、0.1刻み。未評価はnullで、0点と区別する。点数を選択して保存が成功した時だけ鑑賞済みとして表示する。初期値で勝手に評価しない。

基本入力は点数だけ。任意で「今回観た」「過去に観た」「時期不明」を選べる。「今回観た」を明示選択した場合だけ端末の今日を初期値とする。過去は年／年月／年月日の精度で保存。選択しなければ時期不明。

記録後はポスターの追加と短い保存通知を表示し、「詳細」「取り消す」を提供。連続採点で通知や演出が入力を妨げない。動きを抑える設定に対応する。

既存作品の点数変更では、作品数と鑑賞時期を変えない。削除は点数操作から独立させ、通常の取り消しができる設計にする。初期版では再鑑賞イベントを増やさず1作品1記録。将来の拡張のために登録日時・更新日時・鑑賞時期を別フィールドとして扱う。

## 集計の定義

| 指標 | 定義 |
| --- | --- |
| 累計 | 採点がある映画IDの重複しない件数。「実際の生涯鑑賞本数」とは断定しない |
| 今年 | 指定年が分かる記録作品数。年のみの記録も含む |
| 今月／月別 | 年月以上の精度がある作品だけを対象 |
| カレンダー週・日 | 年月日まで分かる作品だけを対象 |
| 邦画 | 製作国に日本を含む作品。国際共同製作も含む旨を説明 |
| 洋画 | 製作国が既知で、日本を含まない作品。国不明は別枠 |
| 国別 | 共同製作は関係する各国に1件ずつ。合計が累計と一致しない旨を説明 |
| 監督別 | 監督IDで集約。共同監督は各監督へ計上。表記揺れで別人にしない |
| 平均点 | 有効な採点の平均と件数を併記。0点も含む |
| 鑑賞時間 | 正式な上映時間がある作品だけの合計。「上映時間ベース」と対象件数を示す |

部分日付は文字列と精度を保持し、UTC日時へ無理に変換しない。年境界・うるう日・端末タイムゾーン変更でも日付をずらさない。

映画賞は賞・部門・開催年・受賞／候補を区別。映画自体の受賞と出演者・スタッフの受賞を区別する。出典付きの対象一覧が確定した範囲のみ分母を表示する。データがない状態で「受賞なし」としない。

## 保存・既存データ・機能間の境界

アカウントなしの試作では端末・ブラウザ内保存と既存バックアップを使用する。自動クラウド同期・端末移行を保証しない。「このブラウザに保存」とバックアップへの入口を常設する。公開サービスとして長期利用を促す前に、復元体験と同期方針を別途評価する。

既存のランキング・候補・Ocean・旧記録キーは削除・一括改名しない。旧記録は読取り互換アダプターを介し、新しい日付等は明示的なバージョン付き追加データとして扱う。既存の未知フィールドを保持する。既存の未採点鑑賞済み記録は削除せず「旧形式・未評価」として別表示し、今回の採点ベース集計には含めない。

現行のpreview/ocean/js/viewing-records.jsでは0点・評価解除が削除につながるため、そのAPIを新画面からそのまま呼ばない。0点保存、評価編集、削除を独立した操作として実装・検証する必要がある。保存失敗を一時メモリ成功で隠さず、画面に永続化できなかった旨と入力の保持を表示する。

統計は記録を正として導出し、別の本数カウンターを独立更新しない。作品メタデータは記録と分離し、情報更新で本人の点数や鑑賞日を変更しない。将来の同期に向け、記録APIの境界をUIから分離するが、今回認証・外部DBは導入しない。

Oceanへの表示・連動を通常記録の保存条件にしない。実験室から既存の状態へ到達可能にし、今回の新画面のために既存の生態系状態を初期化しない。Movie DNAは公開機能としての完成確認前に、この試作に含めたと表示しない。

## データと費用

既存の許可された作品データ・API・ローカルキャッシュを再利用する。追加の有料API、課金付きAI生成、スクレイピングは導入しない。分析・集計は決定的なローカル計算とする。

監督・製作国・年代等は取得できた作品情報に基づく。情報不足をユーザーに必須入力させない。映画賞のデータ整備は別の作業単位とし、確認できた範囲だけでコレクションを作る。

## 試作の順序と評価

1. 合成データによる3画面の比較用試作。0本・5本・20本・200本・1000本で見え方を確認する。本番データと混在させない。
2. 採点・永続化・編集・削除取消・バックアップ復元を接続。映画棚と累計、既知時期のカレンダーを同一記録から更新する。
3. 国×年代の地図、監督別一覧、プロフィールを接続。メタデータ不足時の表示を検証する。
4. 映画賞棚・共有カード・詳細な監督×年代を追加。別の受け入れ条件を設ける。

各画面の試作で確認する問い：ポスターが数本増えただけでも嬉しいか。地図のマスから観た作品へ迷わず戻れるか。プロフィールを自分の記録として残したいか。20本登録するまでの操作に無駄がないか。

機能の成功を利用者調査済みとは扱わない。試作の画面レビューで、3つの楽しさが伝わるかを判断する。

## 実装時の受け入れ条件

- 採点を保存→棚・累計・該当する日付集計が一致→再読み込み後も一致。
- 0点は記録として保持。点数編集で本数・日付は変わらない。
- 時期不明、年のみ、年月、年月日の各集計を区別する。
- 共同製作、共同監督、メタデータ不明、画像なしで誤集計や空画面を作らない。
- 旧ランキング・旧Ocean・未知フィールドを保護。新旧形式のエクスポート／復元が成立する。
- 容量超過・保存拒否・壊れた既存JSONを検出し、成功と誤表示しない。
- 390px、ライト／ダーク、キーボード、読み上げ、動き抑制に対応。ページ横はみ出しなし。
- 合成1000件で集計・絞り込みの正しさを検証。操作を継続できる応答時間を測定する。
- 実装後は共有品質ゲート・Chromium／WebKit検証、プレビュー、本番反映の確認を経る。実機Safariは利用可能な実機で別途確認する。

## 2026-10-16 アトラス試作の追加合意

ユーザーは映画地図の国以外の切り口と、より視覚的な新規性を希望し、世界地図・ジャンル・映画賞の比較試作を承認した。従来の国×年代マトリクスを今回の試作では置き換える。

- 世界地図：Natural Earthのpublic domainベクターデータを埋め込み、採点済み映画の製作国を色分け。小国は44px以上の国名ボタンからも選択する。撮影地・舞台と混同しない。
- ジャンル星図：主要6ジャンルと、同一作品の複数ジャンルの重なりを線の太さで示す。位置は固定レイアウトであり、AIによる意味距離・嗜好推定ではない。ポスターは最大24作品の抜粋。未知ジャンルは注記する。
- 映画賞：既存awards.jsonに公式出典付きで収録され、デモの作品名と照合した作品賞・パルムドールの受賞作だけを掲載。未採点と鑑賞済みを断定しない。分母はデモ収録範囲と明記。
- 新しい記録は現在の表示にも反映。実際のブラウザ保存や本番アプリへの接続はしない。
- Natural Earth出典：https://www.naturalearthdata.com/about/terms-of-use/ 。データは公式メンテナのnatural-earth-vectorから取得し、座標を簡略化してSVG化。追加の外部地図APIは使わない。

## 2026-10-16 全追加案の試作範囲

ユーザーが「ぜんぶやって」と承認したため、同じ隔離試作に以下を実装する。本番反映・アカウント・実ユーザーデータには接続しない。

- 映画賞：授賞年代ごとの横スクロール回廊、授賞年別ボード、賞別の背表紙。全受賞作品を網羅せず、デモ収録範囲で採点数を示す。
- 監督：収録作品の公開年表、ピン留め、採点済み作品の点数順からマイベストの棚を作成。
- 年代：公開年代別ポスター棚と作品一覧。
- 高評価地図：世界地図・ジャンル・年代で本数／自分の平均点を切替。平均点の対象件数を一覧で確認可能。
- 俳優：既存映画データで出演を確認できた作品だけを一覧化。情報不足を未出演としない。
- シリーズ：ダークナイト、ゴッドファーザー、ロード・オブ・ザ・リングの三部作、およびブレードランナー2作品を明示的に構成し、派生作やリメイクを自動混入しない。
- 自由なコレクション：名前40文字、紹介300文字、採点済み作品1本以上。作成、編集、作品順変更、棚の削除・取消。元の採点は変えない。
- 映画年鑑：鑑賞年の選択、本数・高評価作品・監督・国・月別推移。年のみの記録は年合計へ、時期不明は累計へ。PNGカードはローカルcanvasで作品名と数字を出力し、外部画像や個人情報を送信しない。
- プロフィール：採点済み作品から1〜4作品を選んで飾る。

この試作の変更はメモリ内のみ。再読み込みで戻る。アプリの既存マイランキングを上書きする実装ではなく、新しい棚と年鑑の体験を評価する。
