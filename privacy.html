Privacy

Cinemapは個人・非商用の映画情報プロジェクトです。現在、アカウント登録、決済、広告、位置情報の取得、個人情報の入力を必要とする機能は提供していません。

端末内データ

My Cinemap等の一部設定・リストはブラウザのlocalStorageに保存される場合があります。Cinemapのサーバーへユーザーアカウントとして送信・保存するものではありません。ブラウザのサイトデータを消去すると削除されます。

外部データサービス

映画情報等の取得に、Creditsに記載した外部サービスを利用します。外部リンク先では各サービスのプライバシーポリシー・利用規約が適用されます。

Credits / Data Sources

YouTube API Services

CRITIC MAPの「人間の批評・考察」機能は、有効化されている場合にYouTube Data API v3を利用して、作品名とCinemap独自の論点を検索語として批評・考察動画を検索します。YouTubeへのログインやYouTubeアカウントの認可は要求しません。APIキーはサーバー側で管理し、ブラウザへ公開しません。

Cinemapはこの機能で取得した動画本体をダウンロード・保存せず、動画タイトル、チャンネル名、公開日、サムネイル、YouTubeリンクを検索結果として表示します。検索結果をCinemapのデータベースへ恒久保存しません。論点分類はCinemap独自であり、YouTubeが作成または推奨した分類ではありません。

この機能を初めて利用する際、PrivacyとYouTube利用規約への同意を確認します。同意状態はブラウザのlocalStorageに保存され、サイトデータを削除すると消去されます。

問い合わせ・変更

新しい外部サービスやユーザーデータを扱う機能を追加する場合は、本番公開前にデータ取得・保存・削除・第三者提供の有無を見直します。許諾や条件が不明な連携は有効化しません。
