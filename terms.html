利用規約

Cinemapは個人・非商用の映画情報プロジェクトです。本サービスを利用することで、本規約に同意したものとみなします。

YouTube API Services

Cinemapの「人間の批評・考察」機能が有効な場合、YouTube API Servicesを利用します。この機能を利用するユーザーは、YouTubeの利用規約にも拘束されることに同意するものとします。
